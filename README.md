# agentforgeAi
Open-source operating system for AI agents. Build once. Run anywhere.

Open-source platform for building AI agents.

Build agents once. Run them anywhere.

## Features
- Multi-model support
- Memory system
- Tool plugins
- Agent runtime
  
## Why AgentForge?

Today's AI agent ecosystem is fragmented.

Every framework introduces:
- Different memory systems
- Different tool interfaces
- Different workflows
- Different model integrations

Developers spend more time adapting infrastructure
than building intelligent systems.

AgentForge solves this problem.
